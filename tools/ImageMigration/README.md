# Image migration (blob → file storage)

One-time scripts used for the switch from database-blob images to
file-based storage (`feature/file-based-images`).

1. `export_old_images.ps1` — exports every remaining `varbinary(max)` image
   column to `wwwroot/uploads/<folder>/`, and writes `apply_image_paths.sql`
   with the matching `UPDATE ... SET *Path` statements. Safe to re-run.
2. `apply_image_paths.sql` — generated by step 1. Run once with sqlcmd
   after `dotnet ef database update` has applied the migration that adds
   the `*Path` columns.
3. `seed_specialty_categories.sql` — inserts the 34 specialty advice
   categories (with icons under `wwwroot/uploads/advices/specialty-*.png`).
   Guarded with `IF NOT EXISTS` checks against the category's *original*
   (Persian) name, so run it before `rename_categories_to_english.sql`,
   not after — running it again post-rename will insert duplicates.
4. `rename_categories_to_english.sql` — renames those 34 categories from
   Persian to English, matched by icon path. Re-running it is harmless
   (renaming an already-English row to the same English name is a no-op).
5. `category_ids.txt` — reference snapshot of the 34 seeded categories
   (Id, English name, icon path) after steps 3-4 were first run.
